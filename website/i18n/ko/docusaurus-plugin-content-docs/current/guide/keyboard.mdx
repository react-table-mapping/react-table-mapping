# 키보드와 접근성

마우스로 할 수 있는 모든 일을 키보드로도 할 수 있습니다. 필드 연결, 연결 삭제, 행 삭제가 모두 가능합니다.

## Tab 동작 방식

보드는 Tab을 가두지 않습니다. 보드에는 다섯 개의 그룹이 있고, 각 그룹은 **탭 정지 지점 하나**이며 마지막에 있던 위치를 기억합니다. 그래서 행이 200개인 보드도 400번이 아니라 다섯 번만 누르면 지나갈 수 있습니다.

| 그룹 | 담고 있는 것 |
| --- | --- |
| 소스 커넥터 | 각 소스 행의 점 |
| 매핑 선 | 두 테이블 사이의 모든 선 |
| 타깃 커넥터 | 각 타깃 행의 점 |
| 소스 삭제 버튼 | 각 소스 행의 `−` 버튼 |
| 타깃 삭제 버튼 | 각 타깃 행의 `−` 버튼 |

Tab은 다음 그룹으로, Shift+Tab은 이전 그룹으로 이동합니다. 그룹 안에서는 화살표 키로 항목 사이를 이동합니다. 그룹을 떠났다가 돌아오면 떠난 항목에 포커스가 놓입니다. Alt, Ctrl, Meta와 함께 누른 키는 브라우저에 맡깁니다(Alt+Left는 여전히 뒤로 가기입니다).

## 키 목록

### 커넥터

| 키 | 동작 |
| --- | --- |
| 위/아래 (또는 왼쪽/오른쪽) | 같은 열의 이전/다음 커넥터로 이동하며, 양 끝에서는 반대쪽으로 순환합니다 |
| Home / End | 같은 열의 첫/마지막 커넥터 |
| 소스에서 Enter 또는 Space | 연결을 시작하고 포커스를 타깃으로 옮깁니다 |
| 연결 중 타깃에서 위/아래 | 이전/다음 타깃으로 이동 |
| 연결 중 타깃에서 Enter 또는 Space | 연결 확정 |
| Escape | 연결 취소 |

### 매핑 선

| 키 | 동작 |
| --- | --- |
| 위/아래 (또는 왼쪽/오른쪽) | 이전/다음 선으로 이동하며 순환합니다 |
| Home / End | 첫/마지막 선 |
| Enter, Space, Delete, Backspace | 선 삭제 |

Shift+Delete와 Shift+Backspace는 무시합니다. 브라우저 자체 단축키이기 때문입니다.

### 삭제 버튼

| 키 | 동작 |
| --- | --- |
| 위/아래 | 이전/다음 행의 버튼으로 이동하며 순환합니다 |
| Home / End | 첫/마지막 행의 버튼 |
| Enter 또는 Space | 행 삭제 |

## 키보드로 연결하기

1. 소스 커넥터에 포커스를 두고 Enter를 누릅니다. 포커스가 타깃으로 이동하며, 마지막으로 선택했던 타깃에서 시작합니다(처음에는 첫 번째 타깃입니다).
2. 화살표 키로 타깃 사이를 이동합니다.
3. Enter를 눌러 연결합니다. 포커스는 시작한 소스로 돌아오므로, 다시 Enter를 누르면 방금 선택한 타깃에서 다음 연결이 시작됩니다.

Escape를 누르면 취소되며 역시 소스로 포커스가 돌아옵니다. Tab을 누르거나 다른 곳을 클릭하는 등 포커스가 다른 곳으로 이동해도 취소됩니다. 연결이 진행 중일 때는 다른 연결을 시작할 수 없습니다.

## 삭제 후 포커스 위치

삭제해도 포커스가 페이지 맨 위로 떨어지지 않습니다.

- **선을 삭제하면** 포커스가 이웃한 선으로 이동합니다. 마지막 선을 삭제하면 소스 커넥터로 이동합니다.
- **행을 삭제하면** 같은 열의 다음 행 삭제 버튼으로 이동합니다.

## 마우스와 키보드를 함께 쓸 때

- **드래그 없이 커넥터를 클릭하면 Enter와 같게 동작합니다.** 소스를 클릭한 뒤 타깃을 클릭하면 됩니다. 브라우즈 모드의 스크린리더가 커넥터를 활성화하는 방식도 이것입니다.
- **연결 진행 중에 소스를 누르면 그 소스로 넘어갑니다.** 같은 소스를 누르면 취소되고, 다른 소스를 누르면 그 소스로 전환됩니다.
- **선 위에 마우스를 올리면 붉은 띠가 표시됩니다.** 띠는 클릭하면 삭제되는 영역을 보여 줍니다. 키보드로 도달한 선에도 같은 띠가 표시됩니다.
- **마우스를 움직이면 키보드 강조가 사라집니다.** 선에서 다시 키를 누르면 나타납니다.

## 스크린리더

### 이름과 랜드마크

보드는 이름이 붙은 랜드마크이며 기본 이름은 `Field mapping`입니다. 한 페이지에 보드가 여러 개라면 `aria-label`로 이름을 지정해 주세요. `id`를 지정하면 건너뛰기 링크가 가리킬 대상이 생깁니다. 해당 요소는 포커스를 받을 수 있어서, 링크를 따라가면 포커스가 보드로 이동합니다.

```tsx
<TableMapping id="field-board" aria-label="Customer import mapping" /* ... */ />
```

커넥터는 필드 이름 뒤에 이미 연결된 대상과 눌렀을 때 하는 일이 붙어서 읽힙니다. 예를 들어 `email, connected to user_email. Press Enter to start a connection`처럼 읽힙니다. 연결 중에는 타깃이 `Press Enter to connect, Escape to cancel`로 읽힙니다. 매핑 선은 연결한 두 필드의 이름이 붙은 버튼으로 읽힙니다. 삭제 버튼의 이름은 `Remove` 뒤에 행 설명이 붙습니다.

### 라이브 안내

그림은 스스로 아무 말도 하지 않으므로, 보드는 시각적으로 숨겨진 라이브 영역(`role="status"`, `aria-live="polite"`)을 보드 루트의 마지막 자식으로 렌더링합니다. 기본 메시지는 다음과 같습니다.

| 시점 | 메시지 |
| --- | --- |
| 연결 시작 | `Started connecting from {source}. Choose a target and press Enter to connect, or Escape to cancel.` |
| 연결됨 | `Connected {source} to {target}. {total} connection(s) total.` |
| 삭제됨 | `Removed {mapping}. {total} connection(s) remaining.` |
| 취소됨 | `Cancelled connecting from {source}.` |
| 전체 삭제 | `Removed all {count} connections.` |

메시지는 영어입니다. 번역하려면 [헤드리스 훅](./headless.mdx)으로 보드를 구성하고 `useMappingBoard`에 `announcements`를 전달해 주세요.

### NVDA: 브라우즈 모드와 포커스 모드

NVDA에는 두 가지 모드가 있고 화살표 키를 다르게 처리합니다. `NVDA+Space`로 전환합니다. 삐 소리가 나면 브라우즈 모드, 찰칵 소리가 나면 포커스 모드입니다.

- **브라우즈 모드(삐).** NVDA가 화살표 키를 가상 커서에 사용하므로 보드의 화살표 이동은 동작하지 않습니다. 가상 커서를 아래로 움직여 커넥터까지 간 뒤 Enter를 누르면 NVDA가 클릭을 보내고, 이는 Enter와 똑같이 연결됩니다. 이어서 타깃까지 내려가 다시 Enter를 누릅니다.
- **포커스 모드(찰칵).** 화살표 키, Home, End가 보드에 전달되므로 위의 표가 모두 동작합니다.

커넥터는 일반 버튼이라 NVDA가 포커스 모드로 자동 전환하지 않습니다. 화살표 키가 필요하면 `NVDA+Space`를 눌러 주세요.
