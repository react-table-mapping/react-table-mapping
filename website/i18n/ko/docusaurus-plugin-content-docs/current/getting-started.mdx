# 시작하기

## 설치

```bash
yarn add react-table-mapping
# 또는
npm install react-table-mapping
# 또는
pnpm add react-table-mapping
```

## 피어 의존성

앱에 다음 패키지가 설치되어 있어야 합니다.

- `react`, `react-dom` (19)
- `@radix-ui/react-select`
- `@radix-ui/react-slot`

## 스타일 가져오기

```tsx
import 'react-table-mapping/styles';
```
