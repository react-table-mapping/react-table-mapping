# 변경 이력

## Unreleased

- **매핑 선**: 포인터 아래의 선, 또는 키보드로 도달한 선에 클릭하면 삭제되는 영역을 붉은 띠로 표시합니다. 마우스로 누르기만 하고 클릭하지 않은 선이 포인터가 떠난 뒤에도 강조된 채 남지 않으며, 선 위에 hover하면 포커스를 가진 선보다 우선합니다. 브라우저가 포인터가 선을 떠난 것을 놓쳐도 강조가 남지 않고, 마우스를 움직이면 선에서 키를 누를 때까지 키보드 강조가 숨겨집니다.
- **키보드**: 키보드로 연결을 확정하면 포커스가 타깃에 남지 않고 연결을 시작한 소스로 돌아갑니다. 소스에서 다시 Enter를 누르면 마지막으로 고른 타깃부터 다음 연결을 시작합니다.
- **키보드**: 모든 매핑 선이 하나의 탭 정지점을 공유합니다. 화살표 키와 Home·End로 선 사이를 이동하고, Enter·Space·Delete·Backspace로 선을 삭제합니다.
- **키보드**: Home·End로 열의 첫 번째·마지막 커넥터로 이동합니다.
- **키보드**: 각 열의 행 삭제 버튼이 하나의 탭 정지점이 되었습니다. 화살표 키와 Home·End로 이동하고, Enter·Space로 행을 삭제합니다.
- **키보드**: 연결을 그리는 중에 포커스가 커넥터 밖으로 나가면 연결이 취소됩니다.
- **접근성**: 매핑 선을 더 이상 스크린리더에서 숨기지 않습니다. 커넥터는 이미 연결된 대상을 읽어 주고, 행 삭제 버튼에는 이름이 생겼습니다.
- **접근성**: 선이나 행을 삭제해도 포커스가 페이지 맨 위로 떨어지지 않고 보드에 남습니다.
- **DOM**: 보드 루트의 마지막 자식으로 시각적으로 숨긴 라이브 영역을 렌더링해 연결과 삭제를 스크린리더에 알립니다. 화살표 마커 id에 보드마다 다른 접미사가 붙습니다(`arrowhead-normal-…`, `arrowhead-hover-…`). 한 페이지의 두 보드가 같은 id를 공유하지 않게 하기 위해서이며, `#arrowhead-normal`이나 `#arrowhead-hover`를 선택하는 스타일·스크립트는 접두사로 맞춰야 합니다.
- **레이아웃**: 행마다 내용 너비가 달라도 표의 열이 행끼리 맞춰지고, 헤더도 열 위에 정렬됩니다. 긴 셀렉트 옵션 때문에 한 행의 열만 어긋나는 일이 없습니다.
- **매핑 선**: `straight` 선도 `bezier`·`step`처럼 타깃 커넥터까지 그려집니다. 이전에는 7px 앞에서 끝났기 때문에, 이제 어떤 타입이든 화살표와 커넥터 사이 간격이 같습니다. `/core`의 `createLinePath`는 그대로이며, 직접 호출하면 기본값으로 7px 앞에서 끝납니다.
- **다크 테마**: 다크 테마에서 행 삭제 버튼이 어두운 색으로 바뀌고 아이콘도 보입니다. 이전에는 스타일시트에 정의되지 않은 색 토큰을 읽어서 흰색으로 남아 있었습니다.
- **연결**: 드래그하지 않고 커넥터를 클릭하면 연결이 시작되고, 타깃을 클릭하면 완료됩니다. Enter와 같습니다. 스크린리더의 브라우즈 모드도 이 방식으로 커넥터를 누릅니다. 드래그는 이전처럼 동작하며, 드래그가 끝날 때 생기는 클릭은 무시합니다. 이렇게 시작한 연결이 타깃을 기다리는 동안 소스를 누르면 그 소스가 우선합니다. 연결을 취소하고 그 자리에서 드래그를 시작합니다. 같은 소스를 다시 클릭하면 연결이 꺼지고, 다른 소스를 클릭하면 그쪽으로 옮겨 갑니다.
